# VC SAR — Side-Scan Sonar Field Checklist

Static, offline-capable HTML checklist for the Marine Sonic Technology Sea Scan ARC Explorer Mk II (900/1800 kHz).

## Use locally

Open `index.html` in a modern web browser. No installation, server, build tools, or internet connection required.

## Publish using GitHub Pages

1. Create a new GitHub repository (for example, `vc-sar-sonar-checklist`).
2. Upload `index.html` and `README.md` to the repository root, and commit.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main`, folder `/ (root)`, and save.
6. GitHub will display your published Pages URL when deployment finishes.

## Checklist behavior

- Checking an item updates the progress bar and section totals.
- Mission details, notes, checked items, and expanded sections are saved automatically in this browser's local storage.
- **Copy report** copies the full checklist and mission data to the clipboard.
- **Download report** saves a plain-text mission record.
- **Print** uses a clean printable format.
- **Reset** clears this browser's saved mission data after confirmation.

**Important:** Browser local storage is device/browser-specific and is not synchronized with GitHub. Avoid entering sensitive operational details on shared devices. Export the report before clearing browser data.
